# 第 04 站 · 看清对手

**要回答：** 别人做了吗？凭什么是我们？
**交付：** `04-竞品分析.md`（模板：[templates/04-竞品分析.md](../templates/04-竞品分析.md)）

这一站开始连续跑，不等用户确认；遇到 SKILL.md 列出的停顿条件再停。

## 五步

### 1. 定目的

先定为哪个决定做分析，目的不同看的东西不同。

| 目的 | 回答 | 重点看 |
|---|---|---|
| 0 → 1 | 要不要做？ | 市场、格局、有没有空白 |
| 1 → N | 要不要迭代？先迭代哪个？ | 对手的功能、用户差评 |
| 对手出招 | 要不要跟？ | 它为什么做、用户买不买账 |
| 定价 | 收多少钱？ | 定价页、成本结构、收费点 |

### 2. 找竞品：四类都要有

| 类型 | 定义 |
|---|---|
| 直接竞品 | 做一样的事，抢一样的人 |
| 间接竞品 | 同一个需求，换一种方式满足 |
| 替代品 | 用户现在怎么凑合（来自第 01 站，常被忽略，往往是最大的对手） |
| 潜在竞品 | 有能力进来、还没进来的（大平台、硬件厂商、通用大模型本身） |

AI 产品必须把「通用大模型直接用」列为潜在竞品或替代品，并回答它为什么不够。

### 3. 定维度：四层 + 市场层

| 层 | 比什么 |
|---|---|
| 市场层 | 蛋糕多大、什么阶段、谁在抢、一句话定位 |
| 用户层 | 目标用户、用户旅程、完整输出物 |
| 技术层 | 流程、人机分工、Agent 设计 |
| 模型层 | 用什么模型、为什么 |
| 基础层 | 数据来源、成本、定价 |

几家竞品横着放在同一张表里比，每格带来源。

### 4. 收信息

| 去哪 | 看什么 |
|---|---|
| 自己用一遍 | 注册、付费、走完主流程，记录步数和耗时 |
| 应用商店 | 5 星好评在夸什么、1 星差评在骂什么 |
| 社区（小红书、知乎、B 站、Reddit 等） | 吐槽帖、测评 |
| 官网、财报 | 定价页、收入、成本 |
| 融资新闻、招聘网站 | 谁在投、谁在招人、在招什么岗位 |
| 第三方数据 | 下载量、流量趋势 |

**你的做法**：有联网搜索工具时，主动按四类竞品逐个搜，每条信息附链接和获取日期，标【公开资料】。拿不到的（如对手内部数据）写「未获取」，不估。用户手上有实测数据的，标【实测】并写样本量。

1→N 项目尽量做**竞品实测**：同一批真实任务，自己和对手各跑一遍，按 3 到 5 个维度打分，写清样本量和评分方式；也记录「用户首选谁」。经常会出现「某项分数我们最高，用户却不选我们」，这是最有价值的发现，要追问为什么。

### 5. 下结论

**先让 AI 唱反调。** 别问「为什么我的想法会成功」，越问越自信。要用下面这个问法，你自己对自己执行一遍，把结果写进产物：

> 给出最有说服力的论证，说明为什么这个领域的某个竞争对手会成功，而我们会失败。

两条纪律：每个数据标来源；AI 会顺着你说，所以反方论证要具体到对手名字和机制。

**再写差异化公式**：

> 盯 **X** 用户，他最在乎 **Y**，竞品做不了，因为 **Z**。

- 差异从三处找：用户、需求、场景。方向是更垂直、更深、更专。
- Z 必须是结构性原因（数据、渠道、成本结构、合规资质、场景独占、组织能力），不能是「我们做得更用心」。
- **Z 填不出来时停下来问用户**：要么换一个 X 或 Y，要么承认没有差异化，把「要不要做」带进第 06 站的决策矩阵。

1→N 项目的结论落到：**学它的做法，不比它的规模。** 列出对手做对了什么，我们只补最重要、最紧急、最适合自己的。
