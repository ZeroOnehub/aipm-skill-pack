# 拾阶 · 开发文件夹

拾阶把需求和方案想清楚以后，把每个产品交接到这里写代码。拾阶的工作区只放文档，代码都在这里。

| 位置 | 是什么 | 谁用 |
| --- | --- | --- |
| `开始看这里.md` | 产品经理的操作说明：怎么开工、每个阶段做什么、怎么核对 | 你 |
| `AGENTS.md`、`CLAUDE.md` | 编码 AI 的规则卡（`CLAUDE.md` 只是给 Claude Code 的引用） | 编码 AI |
| `docs/手册/` | 三份技术手册：通用技术栈、前端、上线部署（腾讯云开发） | 编码 AI |
| `docs/PRD模板.md` | 不经过拾阶、直接在这里做产品时用的 8 字段 PRD 模板 | 编码 AI |
| `verify.sh` | 自检脚本：测试、密钥、重启恢复、前端构建、文件齐全五项由它判 | 编码 AI，你也可以自己跑 |
| `projects/<产品名>/` | 一个产品一个文件夹：需求、交接资料、代码、证据包 | 你和编码 AI |

开工方法见 [开始看这里.md](开始看这里.md)。
